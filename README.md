## Portfolio development

This repo hosts [dbaik.github.io](https://dbaik.github.io/). Source lives in [`portfolio/`](portfolio/).

```bash
cd portfolio
npm install
npm run dev
```

Rebuild and publish to site root (`index.html` + hashed `assets/` + favicons):

```bash
cd portfolio
npm run publish
```
