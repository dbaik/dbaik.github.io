# dbaik.github.io

Personal site: **[dbaik.github.io](https://dbaik.github.io/)**

Source is in [`portfolio/`](portfolio/). The published site is `index.html` plus hashed files in `assets/`.

```bash
cd portfolio
npm install
npm run dev
```

Rebuild and copy to the site root:

```bash
cd portfolio
npm run publish
```
